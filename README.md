# JIPAS - Comprehensive School Management System

JIPAS is a multi-role school management and accounting platform built for modern educational institutions.

## Features

- **Multi-Role Portals**: Tailored workflows for Administration, Faculty/Teachers, Chief Accountant, Sub-Accountants, Secretary, and Students.
- **Academic Management**: Class rosters, academic years, terms, departments, grading, and terminal reports.
- **Financial Desk & POS**: Real-time fee billing, POS collections in CFA, bank deposits, expense tracking, and financial auditing.
- **Staff & Payroll**: Attendance tracking, salary structures, payroll generation, and payslips.
- **Security & Access Control**: Granular role-based privileges, security audit trails, and encrypted credential management.

## Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion
- **Tooling**: Vite
- **Database**: Cloud Firestore with robust offline-first local cache synchronization

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

The application runs on `http://localhost:3000`.

### Production Build

```bash
npm run build
```
